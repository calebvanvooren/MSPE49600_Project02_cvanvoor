Description: 
This repository contains the completed analysis for Project 2: Predictive Modeling and Engineering Optimization.
The project builds quadratic surrogate models for Sector 3 time and top speed, validates them, and performs
unconstrained and constrained optimization using grid search, SLSQP, and penalty functions. The final recommended
candidate is the feasible grid solution, which satisfies the top-speed requirement while maintaining competitive
cornering performance.
